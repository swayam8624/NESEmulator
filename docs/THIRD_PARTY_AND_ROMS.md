# Source provenance and redistribution

KairoNES includes emulator implementation code, a pixel-game-engine layer, and ROM/test assets. **Do not assume they all have the same copyright owner or license.**

- `NESEmulator/KairoPixelGameEngine.cppm` is a bundled pixel-game-engine dependency. Its original copyright and license must be checked upstream before redistribution or relicensing.
- `NESEmulator/nestest.nes` and the files in `NESEmulator/roms/` are separate ROM/test assets. A license for the surrounding repository does **not** transfer rights to these files or to commercial game ROMs.
- Some CPU/PPU/bus/mapper patterns resemble educational NES-emulator tutorial implementations. Verify provenance and retain any applicable third-party copyright/attribution requirements before describing the whole codebase as independently authored.

The project's own original contributions may be licensed separately after provenance review. Until that review is complete, this repository does **not** claim an MIT or other blanket open-source grant over third-party code/assets.

If you want to use the project for learning, reading and experimenting with the source is encouraged; redistribution and derivative-work permissions must follow the licenses/permissions of each component. Contributors should preserve existing copyright notices and add a reference to the upstream source when importing code.
